# ADR 0003 — Idioma: código en inglés, interfaz y documentación en español

## Estado
Aceptado.

## Decisión
- Identificadores de código, paquetes, tablas SQL, rutas API y mensajes técnicos: **inglés**.
- Textos visibles para el usuario en ambas aplicaciones (moneda `RD$`, fechas `Vie 23 oct`, etiquetas): **español**.
- Documentación (`docs/`), KDoc en Kotlin y comentarios doc en Go: **español**.
